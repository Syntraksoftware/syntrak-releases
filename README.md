# Syntrak for Mac

Download the latest version from [Releases](https://github.com/Syntraksoftware/syntrak-releases/releases/latest): open the `.dmg` and drag Syntrak to Applications.

Once installed, Syntrak updates itself: when a new version is out, Settings offers it.

This repository holds the installers and the update files only. Every update is signed, and the app installs only what that signature verifies.
