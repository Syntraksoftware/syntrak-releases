# Syntrak for Mac

**[Download the latest version](https://github.com/Syntraksoftware/syntrak-releases/releases/latest)**: open the `.dmg` and drag Syntrak into Applications.

## First time opening Syntrak

macOS checks apps from outside the App Store. Until Syntrak carries Apple's developer signature, the first open needs one extra step. Leave **Allow applications from** as it is.

1. Open **Syntrak**. macOS says it cannot verify the developer: click **Done** (not Move to Trash).
2. Open **System Settings → Privacy & Security** and scroll down to **Security**. Under *Allow applications from* there is now a line *"Syntrak" was blocked to protect your Mac*: click **Open Anyway**.
3. Enter your password or use Touch ID, then click **Open**.

You only do this once. The *Open Anyway* line shows for about an hour after step 1; if it is gone, start again from step 1.

### 第一次打開 Syntrak

1. 打開 **Syntrak**，macOS 會話無法驗證開發者：撳 **完成**（唔好撳「移到垃圾桶」）。
2. 去 **系統設定 → 私隱與安全性**，拉到最下面 **安全性**。喺「允許以下來源的應用程式」下面會多咗一行「已阻止 "Syntrak"」：撳 **仍要打開**。
3. 輸入密碼或者用 Touch ID，再撳 **打開**。

只需要做一次。「仍要打開」只會出現大約一個鐘；搵唔到就由第 1 步重新做。「允許以下來源的應用程式」唔使改。

## Updates

Once installed, Syntrak updates itself: when a new version is out, **Settings → Updates** offers it. Every update is signed, and the app installs only what that signature verifies.

This repository holds the installers and the update files only.
